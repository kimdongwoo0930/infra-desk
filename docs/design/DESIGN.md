# 디자인 스펙

IntelliJ 느낌의 다크 테마. FlatLaf 다크 계열(`FlatDarculaLaf` 또는 `FlatMacDarkLaf`)을 기본으로 하고, 아래 값으로 맞춘다.
목업: `dashboard.html`, `terminal.html`, `add-account.html` (브라우저로 열기).

## 색상
| 용도 | 값 |
|---|---|
| 앱 배경 | `#1E1F22` |
| 패널·사이드바·타이틀바 | `#2B2D30` |
| 터미널 배경 | `#191A1C` |
| 터미널 탭바·상태바 | `#232427` |
| 구분선 | `#393B40` |
| 입력칸 테두리 | `#43454A` |
| 보조 버튼 테두리 | `#4E5157` |
| 기본 텍스트 | `#DFE1E5` |
| 보조 텍스트 | `#B4B8BF` |
| 흐린 텍스트(라벨, 캡션) | `#8C8F94` |
| 포인트(accent) | `#3B73E0` |
| 선택된 목록 항목 배경 | `#2E436E` |
| 실행 중(초록) | 점 `#5FB865`, 배지 배경 `#1F3A24`, 배지 글자 `#7FD184` |

| 경고 로그 | `#E5C07B` |

FlatLaf에서는 `FlatLaf.properties`나 `UIManager`로 `@accentColor`, `@background` 등을 위 값으로 덮어쓴다.

## 타이포
- UI: 한글이 잘 보이는 산세리프 (목업은 IBM Plex Sans KR). 본문 13px, 제목 22px/굵게.
- 코드·터미널·IP: 고정폭 (목업은 JetBrains Mono) 12.5~13px.
- 폰트 파일을 번들할 경우 라이선스(OFL) 확인.

## 공통 규칙
- 모서리: 버튼·입력 6px, 카드 8px, 다이얼로그 12px.
- 버튼 높이 34px. 기본 버튼은 accent 배경 + 흰 글자, 보조 버튼은 투명 배경 + 테두리.
- 아이콘은 선형(outline) 아이콘 세트 하나로 통일 (예: FlatLaf 내장 또는 Tabler/Material 선형 SVG).
- 서버 상태는 색 점으로 표시: 실행 중 = 초록 채운 점, 정지 = 회색 테두리만 있는 점.

## 화면 1: 대시보드 (1280×800 기준)
- **타이틀바** (40px): 앱 이름, "서버 N대 · 계정 N개", 마지막 새로고침 시간, 새로고침 버튼.
- **왼쪽 사이드바** (260px): 서버 검색 입력칸 → 계정별 그룹("Oracle · 계정 A" + 리전) 아래에 서버 항목(상태 점, 이름, CPU% 또는 "정지됨") → 하단에 "계정 추가"(점선 테두리) 버튼과 설정 버튼.
- **오른쪽 본문** (위에서 아래로):
  1. 헤더: 서버 이름 + 상태 배지, 아래 줄에 "계정 · 리전 · Shape". 오른쪽에 [SSH 열기(기본)] [재부팅] [정지(위험)].
  2. 정보 그리드 4열×2행: OCPU/메모리, 공인 IP, 업타임, OS, 부트 볼륨, 사설 IP, 열린 포트, 생성일.
  3. 메트릭 카드 3개 가로 배치: CPU, 메모리, 네트워크. 현재값 크게 + 최근 1시간 라인 그래프.
  4. 미니 터미널 (남은 높이 전부): 탭(서버, 로그) + "크게 보기" 링크.

## 화면 2: SSH 터미널
- 타이틀바: "← 대시보드 / SSH 터미널", 열린 세션 수.
- 왼쪽 큰 영역: 서버별 탭(상태 점, 닫기 X, + 새 세션) → 터미널 → 하단 상태바("연결됨 · user@ip:22", 인코딩·크기).
- 오른쪽 패널 (300px):
  - 저장된 명령어: 이름 + 실제 명령어(고정폭, 흐리게) 카드 목록, + 추가 버튼.
  - 일괄 실행: 서버 체크박스(정지된 서버는 비활성) + 명령어 입력 + "N대에 실행" 버튼.
  - 하단: SFTP 파일 버튼.

## 화면 3: 계정 추가 다이얼로그 (560px 폭)
- 클라우드 선택 3칸: Oracle Cloud(선택됨, accent 2px 테두리), AWS·준비 중, GCP·준비 중(비활성).
- 입력: 표시 이름, Tenancy OCID, User OCID, Fingerprint + 리전(2열), API 개인키 파일(찾아보기 버튼).
- 안내 박스(자물쇠 아이콘): "키는 마스터 비밀번호로 암호화해서 이 PC에만 저장돼요. 서버 SSH 키는 서버를 불러온 뒤 서버별로 등록해요."
- 하단: 왼쪽 [연결 테스트], 오른쪽 [취소] [저장하고 서버 불러오기(기본)].
