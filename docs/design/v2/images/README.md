# images

캔버스에서 각 화면을 PNG로 내보내 아래 이름으로 넣는다. DESIGN-v2.md의 "화면 목록"과 같은 이름이다.

| 파일 이름 | 캔버스의 화면 |
|---|---|
| overview.png | 개요 (새 첫 화면) |
| server-overview.png | 서버 · 개요 탭 |
| server-monitoring.png | 서버 · 모니터링 탭 |
| server-containers.png | 서버 · 컨테이너 탭 |
| server-terminal.png | 서버 · 터미널 탭 |
| server-files.png | 서버 · 파일 탭 (SFTP) |
| dialogs.png | 확인 창 · 읽기 전용 |
| settings.png | 설정 (왼쪽 메뉴로 항목 전환) |
| palette.png | 빠른 실행 (⌘K) |
| activity.png | 활동 기록 |
| agent-panel.png | 에이전트 패널 |
| agent-cases.png | 에이전트 승인 카드 · 경우 9가지 |

설정은 항목마다 화면이 달라서, 필요하면 settings-alerts.png, settings-conn.png처럼 항목별로 더 넣는다.
