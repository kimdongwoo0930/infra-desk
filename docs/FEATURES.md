## 개요

![개요](images/overview.png)

![개요 — 목록 보기](images/overview-list.png)

앱을 열면 가장 먼저 보이는 화면이에요. 계정과 직접 연결한 서버가 모두 카드(또는 목록의 한 줄) 하나씩 나와요.

- 맨 위 네 칸: 실행 중인 서버 수, 평균 CPU, 실행 중인 컨테이너 수.
- 서버 카드: 상태, CPU·메모리·디스크 사용률, 컨테이너 수와 멈춘 수, 업타임. 사용률이 85%를 넘으면 숫자가 경고 색으로 바뀌어요.
- 카드의 **SSH · 파일 · 모니터링** 버튼은 그 서버의 해당 탭으로 이동만 해요. 버튼을 누른다고 바로 접속하지는 않아요.
- 정지된 서버 카드에는 **시작** 버튼이 있어요. 켜지는 데 보통 1~2분 걸려요.
- 위쪽 **카드 | 목록**으로 보기 방식을 바꿀 수 있어요. 목록은 서버 하나가 표의 한 줄이라 서버가 많을 때 한 화면에 더 많이 보여요. 같은 값을 그리므로 바꿔도 서버를 다시 읽지 않고, 고른 방식은 앱을 껐다 켜도 기억해요. 창이 좁아지면 서버 이름과 버튼은 그대로 두고 막대(% 숫자만 남김) → 이름 아래 계정·리전 줄 → 컨테이너·업타임 순서로 줄여요.
- 위쪽 칩으로 전체 / 실행 중 / 정지 서버만 거를 수 있고, 왼쪽 사이드바에서 서버를 검색할 수 있어요. 서버는 계정별(처음 값), 상태별, 묶지 않음 중에서 고른 방식으로 묶여요.

## 서버 정보

서버를 고르면 나오는 **개요** 탭이에요. 업타임, OS, 디스크 사용량, 열린 포트를 SSH로 읽어서 보여줘요.

서버 화면 위쪽에는 상태 배지와 **재부팅 · 정지** 버튼이 있어요. 정지와 재부팅은 되돌리기 어려우니 항상 확인 창을 거쳐요. 직접 연결한 서버에는 켜고 끄는 버튼이 없어요.

## 모니터링

![모니터링 — 1시간](images/monitoring.png)

CPU, 메모리, 네트워크(수신·송신)를 그래프로 보여줘요.

- 기간: **실시간 · 1시간 · 6시간 · 24시간 · 7일**. OCI 서버는 OCI Monitoring에서 1분 간격으로 읽어요. 직접 연결 서버는 SSH로 1분마다 읽고, 1시간만 볼 수 있어요.
- 그래프 위에서 마우스 휠로 확대·축소, 드래그로 이동, 더블 클릭으로 처음 범위로 돌아가요. 세 그래프는 마우스가 가리키는 시각을 함께 보여줘요.
- 오른쪽에 이 기간의 평균·최대(와 그 시각), 디스크 사용량, CPU 알림 기준이 나와요.

![모니터링 — 실시간](images/monitoring-live.png)

**실시간**을 고르면 SSH로 서버의 `/proc`을 2초마다 읽어서 그려요. 켜 둔 걸 잊어도 SSH를 계속 읽지 않도록 10분 뒤에 저절로 꺼져요.

## 컨테이너

![컨테이너](images/containers.png)

서버에 Docker가 있으면 **컨테이너** 탭에서 다룰 수 있어요. 모든 동작은 SSH로 `docker` 명령을 실행하는 방식이에요. Docker 포트(2375)는 열지 않아요.

- 목록: 이름, 이미지, 상태, CPU, 메모리, 네트워크, 포트. 전체 / 실행 중 / 멈춤으로 거르고 이름·이미지로 찾아요.
- 행마다 컨테이너 안 **셸**, **DB 콘솔**(MySQL · PostgreSQL · Redis · MongoDB), **재시작**, **정지/시작** 버튼이 있어요.
- 아래 로그 패널: 컨테이너를 골라 최근 로그를 보고, 경고·오류만 거르고, 글자로 찾아요. **자동 새로고침**을 켜면 10초마다 다시 읽어요(기본은 꺼짐). 별도 창으로 크게 열 수도 있어요.
- 목록은 계속 읽지 않아요. 서버를 고를 때, 새로고침을 누를 때, 컨테이너를 조작한 뒤에만 읽어요.
- `docker`를 쓰려면 서버에서 docker 그룹이거나 비밀번호 없는 `sudo`가 되어야 해요. 자세한 조건은 [README 호환성](../README.md#호환성)에 있어요.

## 파일

![파일](images/files.png)

왼쪽 **내 컴퓨터**와 오른쪽 **서버**를 나란히 두고 SFTP로 파일을 옮겨요.

- 파일을 끌어다 놓으면 업로드·다운로드돼요. Finder·탐색기에서 서버 쪽으로 끌어와도 올라가요.
- 끊긴 전송은 이어받아요. 아래 **전송** 목록에서 진행률, 속도, 남은 시간을 보고 취소하거나 다시 시도해요.
- 새 폴더·새 파일, 이름 바꾸기(F2), 권한 변경(읽기·쓰기·실행 체크 또는 숫자 입력), 삭제. 삭제는 확인을 거쳐요.
- 파일을 **복사**(우클릭 또는 Cmd/Ctrl+C)했다가 붙여넣을 폴더를 열고 창 머리의 **붙여넣기 버튼**(복사해 둔 게 있을 때만 켜져요), 우클릭 메뉴의 "지금 폴더에 붙여넣기", 또는 Cmd/Ctrl+V로 **붙여넣어요**. 붙여넣기는 지금 보고 있는 폴더에 들어가요. 내 컴퓨터↔서버, 같은 서버 안(폴더를 옮길 때), 다른 서버의 파일 탭으로도 붙여넣을 수 있어요. 같은 폴더에 붙여넣으면 이름 뒤에 " 복사"가 붙고, 다른 폴더에서 이름이 겹치면 덮어쓸지 물어봐요. 서버에서 서버로(같은 서버 안 포함) 복사할 때는 내 컴퓨터를 거쳐서(임시 폴더에 받았다가 올려요) 큰 파일은 시간이 걸려요. 이 중간 전송은 아래 전송 목록에 줄로 나오지 않고, 끝나면 결과 줄에 알려요(진행 중인 전송 수에는 들어가요).
- 선택된 항목이 하나일 때 그 항목을 다시 누르면 선택이 풀려요(Cmd/Ctrl 없이도).
- 서버 파일을 **더블클릭**(또는 Enter, [편집], 우클릭 "편집")하면 받지 않고 앱 안의 **편집 창**으로 열어요.

  ![편집 창](images/file-editor.png)

  - **저장**은 [저장] 버튼이나 Cmd/Ctrl+S예요. 서버에 바로 올라가고 전송 목록에는 줄이 생기지 않아요. 결과는 편집 창 오른쪽 위에 나와요. 편집하는 사이 서버에서 파일이 바뀌었으면 덮어쓸지 물어봐요.
  - 고친 내용이 있는 채로 닫으면 "저장하시겠습니까?"가 떠요. **[저장] [저장 안 함] [취소]**이고, 이 창을 X로 닫으면 저장하지 않고 닫아요.
  - 제목의 ●와 오른쪽 위의 "수정됨"이 저장 전이라는 표시예요. 되돌리기는 Cmd/Ctrl+Z, 다시 하기는 Cmd+Shift+Z(Windows는 Ctrl+Y)예요.
  - 파일을 망가뜨리지 않도록 UTF-8 글자 파일만 열어요. 줄바꿈(LF/CRLF)과 UTF-8 BOM은 저장할 때 그대로 돌아가요. 2MB가 넘거나, 이미지·압축 같은 바이너리, EUC-KR 같은 다른 인코딩은 앱 안에서 열지 않고 "내 컴퓨터로 받기"(와 외부 편집기로 열기)를 권해요.
  - 우클릭 **"외부 편집기로 열기"**는 예전 방식이에요: 내 컴퓨터의 편집기로 열고, 거기서 저장하면 서버에 자동으로 올라가요. 위쪽 배너에서 편집을 끝낼 수 있어요.
  - 읽기 모드로 바꾸면 열려 있던 편집 창도 더 저장하지 못해요.
- 서버 쪽의 **숨김 파일** 버튼으로 점으로 시작하는 파일을 보이거나 숨겨요.

## 터미널

![터미널](images/terminal.png)

서버별로 SSH 터미널을 열어요.

- 처음 **접속**을 누르면 사용자 이름과 SSH 키를 정하는 창이 떠요. `~/.ssh/config`에 그 서버가 있으면 값이 미리 채워져요.
- 처음 보는 서버는 호스트 키 지문을 확인하고, 이후에는 키가 바뀌었을 때만 경고해요.
- **＋ 새 세션**에서 서버의 새 셸이나 실행 중인 컨테이너의 셸·DB 콘솔을 열어요.
- 오른쪽 **저장된 명령어**: 자주 쓰는 명령을 카드로 저장해 두고 ▶를 누르면 열려 있는 터미널에 보내요. 우클릭으로 편집·삭제해요.
- 다른 서버로 옮겨도 터미널 세션은 닫히지 않고 숨어 있다가, 돌아오면 그대로 보여요.

## 읽기 모드와 관리 모드

![읽기 모드의 개요](images/overview-readonly.png)

앱은 **항상 읽기 모드**로 시작해요. 창 위쪽의 `읽기 | 관리`로 바꿔요.

- **읽기 모드**: 순수하게 보기만 해요. 서버를 바꾸거나 접속하는 것(서버 시작·정지·재부팅, 터미널·파일 탭, 개요 카드·목록의 [SSH] [파일] [시작], 컨테이너 셸·재시작·정지·시작, 저장된 명령어, 메뉴 막대의 같은 항목), 설정을 바꾸는 것(사이드바의 [계정·서버 추가]와 설정 버튼, 계정 설정·삭제, [SSH 설정], 모니터링 탭의 "설정에서 바꾸기"), 공인 IP를 보이게 하거나 복사하는 버튼이 화면에서 사라져요. 공인 IP는 설정과 상관없이 늘 가려져 있어요. 개요, 서버 정보, 모니터링, 컨테이너 목록과 로그 보기는 그대로예요. 설정이 필요하면 관리 모드로 바꾸세요.
- **관리 모드**: 모든 기능을 써요. 읽기에서 관리로 바꿀 때만 관리 비밀번호를 물어요. 읽기로 돌아갈 때는 묻지 않아요.
- 처음 앱을 켜면 관리 비밀번호(4자 이상)를 먼저 정해야 해요. 바꾸려면 설정 → 보안·안전에서 현재 비밀번호를 입력해요. 5번 연속 틀리면 30초 동안 막아요.
- 잊었다면 [docs/BUILD.md](BUILD.md#실행-옵션)의 `--reset-admin-password`로 지우고 다시 정해요.

## 설정

![설정 — 연결·조회](images/settings.png)

사이드바 아래 톱니바퀴로 열어요. 바꾼 설정은 바로 저장돼요.

- **일반**: 로그인할 때 자동 실행, 시작 화면(개요 또는 지정한 서버), 서버 목록 묶기(계정별 / 상태별 / 묶지 않음). 묶기는 개요의 "묶기" 목록에서도 바꿀 수 있고 사이드바와 개요에 함께 적용돼요. 단축키 목록은 아직 준비 중이에요.
- **연결·조회**: 서버 상태(30초)·메트릭(1분) 조회 주기, 실시간 자동 꺼짐(10분), SSH 연결 새로 맺기(12시간)를 보여줘요. 지금 열려 있는 SSH 연결도 볼 수 있어요. 값은 OCI API 요청 제한을 고려해 정한 것이라 앱에서 바꾸지는 않아요.
- **보안·안전**: 공인 IP 기본으로 가리기(처음 값은 켜짐, 끄면 앱을 열 때부터 보여요. 눈 모양 버튼은 그대로 써요), 관리 비밀번호 바꾸기, 비밀값을 어디에 어떻게 저장하는지(`secrets.vault`, AES-256-GCM, 키는 OS 키체인). 자세한 내용은 [README 보안과 데이터](../README.md#보안과-데이터).
- **업데이트·정보**: 버전, 업데이트 확인, 로그 폴더, 오픈소스 라이선스.

## 메뉴 막대 아이콘

창을 닫아도 앱은 종료되지 않고 메뉴 막대(macOS) / 알림 영역(Windows)에 남아요. 아이콘 메뉴에서 서버 상태를 보고 바로 제어할 수 있고, 새 버전이 나오면 여기에서 알려줘요. 창이 숨어 있는 동안에는 SSH 연결을 조회용 하나만 남겨요.

## 아직 준비 중인 것

화면에 **준비 중** 배지로 보이는 항목이에요. 눌러도 동작하지 않아요.

- 디스코드 알림 (서버 멈춤, 계정 연결 끊김, CPU 고사용)
- 개요의 "확인이 필요해요", 활동 기록
- 서버 화면의 로그 탭
- AWS, GCP 계정

현재 구현 현황은 [PRD](PRD.md)의 "현재 상태"를 따라요.
